# Physics_KIM_Generator 🚀

Генератор тренировочных вариантов КИМ по физике (ЕГЭ и ОГЭ) с оформлением по стандартам ФИПИ, QR-кодами, электронным бланком ответов и облачной проверкой через Google Таблицы и Google Диск.

---

## 📁 Структура проекта

```text
Physics_KIM_Generator/
├── templates/
│   ├── fipi_style.sty       # Макросы оформления КИМ (рамки, номера, QR-код, бланки)
│   ├── ege_ref.tex          # Справочные данные ЕГЭ (константы, приставки, плотности, молярные массы и др.)
│   └── oge_ref.tex          # Справочные данные ОГЭ (константы, сопротивления, температуры плавления/кипения)
├── tasks/
│   ├── images/              # Папка для графиков и схем (.pdf / .png)
│   └── db.json              # Единая база задач ЕГЭ и ОГЭ
├── output/                  # Сюда падают готовые PDF и полные JSON-ключи вариантов
├── web/                     # Статический фронтенд Электронного бланка ответов
│   ├── index.html           # Одностраничное приложение бланка
│   ├── style.css            # Стилизация под клеточки бланка ФИПИ и адаптивный дизайн
│   ├── app.js               # Логика таймера, сжатия фото через Canvas и отправки
│   ├── config.json          # Конфиг веб-приложения (GAS_WEBHOOK_URL)
│   └── variants/            # Публичные манифесты вариантов (БЕЗ ответов и решений)
│       ├── EGE-101.json
│       └── OGE-201.json
├── gas/
│   └── Code.gs              # Исходный код скрипта для Google Apps Script
├── config.json              # Корневой конфиг сборщика (GAS_WEBHOOK_URL, WEB_BASE_URL)
└── build.js                 # Главный скрипт сборки вариантов и манифестов
```

## ⚡ Быстрый старт

### 1. Генерация вариантов КИМ (Node.js)

```powershell
# Генерация варианта ЕГЭ по умолчанию (№101):
node build.js

# Генерация варианта ЕГЭ по конкретным темам:
node build.js --exam=EGE --topics=mechanics --variant=102 --title="Тематический пробник: Механика"

# Генерация варианта ОГЭ (9 класс):
node build.js --exam=OGE --variant=201 --title="Тренировочный вариант ОГЭ №201"

# Только генерация .tex и JSON-манифестов без компиляции PDF:
node build.js --skip-pdf
```

После сборки создаются:
1. `output/KIM_<EXAM>_<VAR>_Student.pdf` — вариант для ученика с QR-кодом для быстрого перехода в электронный бланк;
2. `output/KIM_<EXAM>_<VAR>_Teacher.pdf` — критерии оценивания и решения для преподавателя;
3. `output/KIM_<EXAM>_<VAR>_Key.json` — полный закрытый ключ;
4. `web/variants/<EXAM>-<VAR>.json` — публичный манифест без ответов для фронтенда.

## 🌐 Электронный бланк ответов (`web/`)

Фронтенд готов к деплою на **GitHub Pages**, **Vercel** или любой статический хостинг.

### Локальный запуск бланка:
```powershell
# Через Node.js:
npx serve web

# Или через Python:
python -m http.server 8000 --directory web
```
Откройте в браузере: `http://localhost:8000/?v=EGE-101`

### Возможности веб-бланка:
- **Динамическая загрузка структуры**: сначала запрашивается локальный `web/variants/<ID>.json`; если файла нет (404 на GitHub Pages / Vercel / Netlify), бланк автоматически берёт публичный манифест из GAS (`?action=get_manifest&v=<ID>`) — перезаливать сайт после каждого нового варианта не нужно.
- **Защита ответов**: клиентский манифест `web/variants/` содержит только номера, типы проверки, единицы измерения и баллы. Ответов и решений в коде страницы нет.
- **Таймер**: обратный отсчёт (235 мин для ЕГЭ, 180 мин для ОГЭ) с предупреждением за 15 и 5 минут до конца.
- **Бланк ответов № 1**: поля ввода стилизованы под клеточки бланка ФИПИ (моноширинный шрифт, автозамена точки на запятую, подсказки формата).
- **Бланк ответов № 2**: загрузка рукописных решений с клиентским сжатием фото через `<canvas>` (максимум 1600px, JPEG 0.75, размер снимка с 4–5 МБ сжимается до ~200–300 КБ).

### Публикация на GitHub Pages

- Репозиторий: `https://github.com/znormalnyj-dot/physics-kim`
- Сайт: `https://znormalnyj-dot.github.io/physics-kim/`

Ветка `gh-pages` содержит только содержимое `web/`. После правок фронтенда обновить сайт можно одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy-web.ps1
```

Новые варианты перезаливать не нужно: если `web/variants/<ID>.json` нет, бланк автоматически загружает манифест из GAS.

## ☁️ Интеграция с Google Apps Script (`gas/Code.gs`)

1. Создайте новую **Google Таблицу** на Google Диске;
2. Откройте **Расширения → Apps Script**;
3. Вставьте содержимое файла [`gas/Code.gs`](gas/Code.gs) и сохраните;
4. Нажмите **Начать развертывание → Новое развертывание**:
   - Тип: **Веб-приложение**
   - Выполнять как: **От моего имени**
   - У кого есть доступ: **Все**
5. Скопируйте полученный URL (заканчивается на `/exec`) и вставьте в `config.json`:
   ```json
   {
     "GAS_WEBHOOK_URL": "https://script.google.com/macros/s/.../exec",
     "WEB_BASE_URL": "https://your-username.github.io/kim-blank/"
   }
   ```
6. При каждой сборке `node build.js` ключи будут **автоматически регистрироваться** в вашей Google Таблице на листе `Keys`, а ответы учеников и фото решений будут попадать на лист `Results` и в папку `Physics_KIM_Работы_Учеников` на Google Диске!
7. После обновления `Code.gs` обязательно переразверните новую версию (**Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть**) — иначе веб-бланк не сможет получать манифесты через `?action=get_manifest&v=<ID>`.
8. Публичный URL бланка для QR-кода можно задать прямо в панели преподавателя (`/admin` → «Параметры варианта»). Значение сохраняется в `config.json` и используется `build.js` при генерации QR-кода.
